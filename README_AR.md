# نور الإسلام — مشروع أندرويد أصلي كامل (Native Kotlin + Jetpack Compose)

هذا المشروع هو النسخة الأصلية (Native Android — Kotlin + Jetpack Compose، **بدون WebView**) المطابقة بالكامل لمحتوى ومميزات التطبيق، وجاهز مباشرة لفتحه وبناء ملف التثبيت `APK` في **Android Studio**.

## المميزات والموسوعات المدمجة بالكامل (تعمل بدون نت)
1. **الرئيسية**: لافتة المسجد وصورة الكعبة والمخطوطة القرآنية بدقة عالية (`drawable-nodpi`)، عدّاد حي للصلاة القادمة، آية اليوم، تحدي الصلوات الخمس اليومي، وشبكة الوصول السريع.
2. **القرآن الكريم والتحفيظ والتسميع**:
   - النص العثماني الكامل (١١٤ سورة / ٦,٢٣٦ آية) + **التفسير الميسر** صوتياً (Arabic TTS) ونصياً.
   - **المصحف صفحة بصفحة (١ إلى ٦٠٤ صفحات)** مع شريط تمرير والتنقل بين الأجزاء.
   - **محرك البحث القرآني** بدون تشكيل في جميع آيات المصحف.
   - **٣٦ قارئاً** مع مدير **التنزيل التام بدون إنترنت** (تنزيل سورة واحدة أو جزء عمّ ٣٧ سورة أو مسح الكاش).
   - **تكرار الحفظ** (من آية إلى آية من ١ إلى ١٠ مرات) و**إخفاء الآيات للاختبار**.
   - **استوديو التسميع الذكي بالمايك** (`SpeechRecognizer` + خوارزمية LCS لتلوين الكلمات المتطابقة بالأخضر والمفقودة بالأحمر + التحقق اليدوي بدون نت + نقاط XP).
3. **موسوعة القصص والسير الكاملة (بدون اختصار)**:
   - قصص **٢٥ نبياً** كاملة ومفصّلة مع المعجزات والعبر.
   - سير **٥٥ صحابياً** مصنّفة بالكامل.
   - استماع صوتي للسير (`TextToSpeech`) + متابعة ما تمت قراءته.
4. **المسابقات والألعاب الإسلامية**:
   - **١٠٠ مرحلة متدرجة (٥٠٠ سؤال)** مع نظام النجوم (٣ نجوم) وفتح المراحل ونقاط الخبرة والمستوى.
   - **تحدي السرعة (٦٠ ثانية)** مع سلسلة الإجابات وأفضل نتيجة.
   - **٥٥ لغزاً (أكمل الآية ومن القائل)** مع التلميحات والمراجع.
   - **تحدي الأصدقاء** عبر رمز موحّد ومشاركة النتيجة.
5. **العبادات والأدوات الإسلامية**:
   - **إحصائيات الصلوات والرواتب** مع رسم بياني أسبوعي (٧ أيام) وسلسلة الالتزام و٨ أوسمة.
   - **بوصلة القبلة الحية بمستشعرات الهاتف** (`Accelerometer + Magnetometer`) + ٢٠ مدينة + تحديد الموقع GPS + المذهب الحنفي + التقويم الهجري والميلادي الشهري.
   - **٥٤ حديثاً نبوياً** (بالصوت والنسخ) و**٩٩ اسماً من أسماء الله الحسنى**.
   - **٢٦ ذكراً ودعاءً في ٧ أقسام** بعدادات يومية.
   - **السبحة الإلكترونية بحلقة التسبيح والاهتزاز** + إضافة أذكار مخصصة.
   - **حاسبة الزكاة الشرعية (٢.٥٪)** + **متابعة الختمة (٣٠ جزءاً)**.
   - **تنبيهات النظام المحلية (AlarmManager)** قبل كل صلاة بـ ٣٠ دقيقة وأذكار الصباح والمساء بأوقات مخصصة + زر اختبار الإشعارات.

## خطوات بناء ملف APK
1. فك ضغط الملف بالكامل إلى مجلد على جهازك.
2. افتح مجلد `NoorAlIslamAndroid` من داخل **Android Studio**.
3. انتظر اكتمال مزامنة `Gradle Sync` (تتطلب إنترنت في المرة الأولى لتنزيل مكتبات Compose).
4. اختر `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
